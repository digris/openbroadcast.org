# Historical Archive

Everything under `docs/history/` is historical/reference material and is **not part of the active application codebase**.

## Coding tasks

When working on application code:

- Ignore `docs/history/archive-org/`.
- Do not use archived HTML, JavaScript, CSS, or other captured files as examples of the current architecture or implementation.
- Do not infer current application behavior, dependencies, conventions, or requirements from these files.
- Do not include files under `docs/history/` when searching for current implementations unless the task explicitly concerns project history.
- Historical concepts found here may no longer be relevant to the current application.

The archived pages contain snapshots of previous Open Broadcast websites and applications and may include obsolete application code as well as code injected by the Internet Archive.

## Historical tasks

When a task explicitly concerns the history of Open Broadcast, `docs/history/` may be used as historical source material.

In particular, `docs/history/archive-org/` contains captured historical pages used to document the project's original vision and evolution.

For historical research, treat these files as historical evidence, not as descriptions of the current system.
